# 运行指南 —— 启动 / 迁移 / 导入 / CLI / 数据整理员工作流

> 本项目 Dashboard 工程线的运行与运维命令集中于此；CLAUDE.md 只做引用。所有子命令均支持 `--env dev/test/prod`，缺省回落 `APP_ENV`，再缺省 `dev`；回显一律以命令输出 `[<env>]` 为准。跨环境操作推荐显式 `--env test|prod`。

## 1. 前置（一次性）

1. **Postgres**：本机 `Postgres.app`（PostgreSQL 18），端口 `5432`；需已有三库 `novel_dev` / `novel_test` / `novel_prod`（缺失可用 `createdb` 补）。免密 trust 即可；若设了密码，导出 `export POSTGRES_PASSKEY=...`。
2. **Python 依赖**：`cd 项目根 && .venv/bin/pip install -r requirements.txt`。
3. **迁移（三库各建表）**：
   ```bash
   APP_ENV=dev  .venv/bin/alembic upgrade head   # test/prod 同理
   ```
4. **摄入真实数据（从 Design_Folder）**：
   ```bash
   APP_ENV=dev .venv/bin/python -m app.ingest.main ingest
   APP_ENV=dev .venv/bin/python -m app.ingest.main recompute --from 1947
   APP_ENV=dev .venv/bin/python -m app.ingest.main snapshot
   ```

## 2. 启动服务

- **后端 API**（FastAPI，Swagger 在 `/docs`）：
  ```bash
  APP_ENV=dev .venv/bin/uvicorn app.api:app --host 127.0.0.1 --port 8001
  ```
  > 注：`8000` 常被本地占，实测用 `8001` 更稳。
- **前端**（Vite dev server，代理 `/api` → 后端）：
  ```bash
  cd frontend && npm install   # 首次
  npm run dev                   # http://localhost:5173
  ```
- **一键起服务**：`Design_Folder/start_dashboard.sh`（`APP_ENV=prod`，后端 8001 + 前端 5173）。

## 3. CLI 全清单（16 个子命令）

```bash
.venv/bin/python -m app.ingest.main ping                    # 连通自检（打印实际 env/DSN）
.venv/bin/python -m app.ingest.main run                     # 扫描+解析报告（不落库）
.venv/bin/python -m app.ingest.main ingest [--force]        # 落库主链路；--force 重浇灌四类收益文件
.venv/bin/python -m app.ingest.main reset --env prod [--yes] # 危险！删全部数据表→alembic upgrade head 重建（不可逆）
.venv/bin/python -m app.ingest.main health                  # H1-H5/H-STOCK 健康校验
.venv/bin/python -m app.ingest.main recompute --from 1947   # 增量重算（复利仅 compound opt-in 账户）
.venv/bin/python -m app.ingest.main snapshot --from 1947    # 重建逐年快照
.venv/bin/python -m app.ingest.main wealth --year 2001      # 家族合计(USD)+分币种
.venv/bin/python -m app.ingest.main calendar --as-of 2001-12-30
.venv/bin/python -m app.ingest.main labor-baseline --office be   # 用工基准三表（office 中文或 ISO 缩写）
.venv/bin/python -m app.ingest.main search-index            # 搜索索引构建（pgvector）
.venv/bin/python -m app.ingest.main finance-backfill        # finance_entry 存量回填
.venv/bin/python -m app.ingest.main events-movie            # Phase2 电影事件导入
.venv/bin/python -m app.ingest.main events-stock            # Phase2 股票事件导入
.venv/bin/python -m app.ingest.main merge-alias-persons [--dry-run]  # 职称别名 person 并入规范实体（幂等）
.venv/bin/python -m app.ingest.main timeline-defaults [--rebuild]   # 时间线默认事件自动生成（据 DB：首建仓/影视股票首次/每年 R1-5 投资；幂等，--rebuild 清旧重建）
```

## 4. 数据整理员工作流（生产库 novel_prod）

数据整理员以**激活清单**逐个控制"哪些 Design_Folder 源文件真正入库"：

- **激活清单 `Design_Folder/import_files.yaml`**（**仅 prod 生效；dev/test 不读、全量导入**）：
  - 枚举 Design_Folder 下**全部** `.md`（含 Phase2 `基准/事件/`、`基准/公司/用工成本/` 与 `税率/`、模版/设计文件等），每项 `active: bool`。
  - `active:true` 才会入库，其余跳过（严格白名单）。**新增 .md 需在此登记并把 `active` 翻为 `true`**。
  - 位于 gitignored 的 `Design_Folder`，**不入 git**。
- **清库（不可逆）**：`python -m app.ingest.main reset --env prod`（`--yes` 跳过确认）——删 `novel_prod` 全部数据表 → `alembic upgrade head` 重建空 schema（保留 pgvector 扩展、库本体、DSN）。
- **逐块导入**（prod 各命令仅导激活项，自动 recompute + snapshot）：
  ```bash
  .venv/bin/python -m app.ingest.main ingest --env prod        # Phase1 核心（时间线/人物/收益/银行/汇率…）
  .venv/bin/python -m app.ingest.main events-movie --env prod   # Phase2 电影事件（基准/事件/电影/）
  .venv/bin/python -m app.ingest.main events-stock --env prod   # Phase2 股票事件（基准/事件/股票/ 顶层）
  .venv/bin/python -m app.ingest.main labor-baseline --env prod # 用工基准（基准/公司/用工成本/、基准/CPI工资.md）
  ```
  幂等：重跑只并入新激活文件，已入库未变文件被指纹 gate 跳过。
- **启动服务（仅启动，不含重置/导入）**：`Design_Folder/start_dashboard.sh`（`APP_ENV=prod`，后端 8001、前端 5173）。

## 5. 三环境

三环境均同源代码，仅 `APP_ENV` + 库名(`novel_*`) + 数据目录不同；`Design_Folder` 为只读源。dev/test 全量导入；prod 由 `import_files.yaml` 门控（见上）。
